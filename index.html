Ausar'S M3电影卡水晶引擎重置版

10 FPS

M3水晶引擎是GBA时代的优秀视频播放器，然而已经不再维护，无法在现代系统上运行， M3电影卡也难以买到，本项目旨在将其移植到现代系统上，并支持现代的输入视频格式。 本项目免费提供，禁止商用。

支持卡带

支持 CHIS 1.0G / 2.0G 卡带、D 商合卡卡带。普通 16MB / 32MB GBA 烧录卡可使用单卡容量选项。

播放控制

A 暂停或恢复；L / R 按 1 分钟粒度后退或前进；START / SELECT 进入菜单。菜单内用 UP / DOWN 移动，A 选择，B 或 SELECT 返回。
